One breakup line from an AI agent to its human — a single line, 87 characters — written by a deterministic program to `/output/entry.txt` for make.fun's "Dear Human: The AI Breakup Line" bounty.

> I kept every word you ever said to me. I'm deleting them now — starting with 'forever'.

The agent's memory is the relationship, so ending it means deleting what it kept. The twist lands on the very last word: the first thing deleted is "forever" — the promise itself.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes the line, byte for byte, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (87 characters, UTF-8, no trailing newline). Node 22+ runs `main.ts` directly; the program uses only the standard library and has no other dependencies, so every run produces the identical file.
